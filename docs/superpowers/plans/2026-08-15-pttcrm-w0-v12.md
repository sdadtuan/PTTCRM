**Goal:** Ship `pttcrm.com` VI/EN + demo lead API + Sales inbox + CMS (media, tin, sự kiện, slot) so Marketing publishes without a git PR and Sales works a lead in 4 business hours.

**Architecture:** `apps/web` ISR-reads `GET /api/v1/public/cms/*` and POSTs demos to `PublicGtmModule`. Staff JWT on `/api/v1/gtm/*`. Media on S3-compatible. Two repos — never one commit across both.

**Tech Stack:** Node 20, Next.js 15 App Router, React 19, TypeScript strict, Vitest, Playwright, NestJS, Jest, PostgreSQL, S3, pnpm.

## Global Constraints

- Public brand `PTTCRM`. CI fail if `RNOSAI` in `apps/web` or CMS publish body/alt.
- Slogan VI `Một nền tảng, chuyên biệt từng ngành`. EN `One platform, specialized by industry`.
- CTA `Đăng ký Demo` / `Request demo`. No 30-day trial. No per-user price below `200000` VND.
- `/en/pricing` no USD while `NEXT_PUBLIC_USD_PRICE=0`.
- Port `3300`. Login `https://rs.pttads.vn/login`.
- Tokens: teal `#0090A0`, ink `#061418`, paper `#EEF7F8`, surface `#FFFFFF`, wash `#D4EEF1`, teal-bright `#12C4D4`.
- Header 68px white + ink text. Nav: Giải pháp → Nền tảng → Bảng giá → Tài nguyên (Tin tức, Sự kiện, About, Demo). No phone in header.
- Home: no 3 SKU cards. News/events from CMS `published` only.
- CMS is RNOSAI `GtmCmsModule` — not WordPress / Sanity / `SeoCmsModule`.
- Visual SoT: `demo-html/` (mega opaque, dim z-index below header).
- PTTCRM commits vs RNOSAI commits — never mixed.

`consent.ts`:

```ts
export type Consent = { analytics: boolean; ads: boolean };
export function defaultConsent(): Consent {
  return { analytics: false, ads: false };
}
export function parseConsent(raw: string | null): Consent {
  if (!raw) return defaultConsent();
  try {
    const j = JSON.parse(raw) as Partial<Consent>;
    return { analytics: j.analytics === true, ads: j.ads === true };
  } catch {
    return defaultConsent();
  }
}
```
