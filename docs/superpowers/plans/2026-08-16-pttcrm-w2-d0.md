**Goal:** Mở cửa English sâu hơn: hiện list price USD trên `/en/pricing`, thanh toán Stripe test, GDPR/DPA EN, hub Tài nguyên, và sandbox shell tiếng Anh (login → lead list → 1 industry board) — **không** dịch 129 màn ops-web.

**Architecture:** PTTCRM thêm flag `NEXT_PUBLIC_USD_PRICE`, copy USD trong repo, nút Stripe Checkout gọi `PublicGtmModule`. RNOSAI thêm `gtm_payment` + Stripe webhook + bridge auth sandbox sang staff JWT có cap hẹp. Sandbox visitor chỉ thấy 3 route EN whitelist; mọi route khác → trang «Not in sandbox».

**Tech Stack:** Node 20, Next.js 15, Vitest, Playwright, NestJS, Jest, PostgreSQL, Stripe SDK (`stripe@^17`), pdfkit hoặc static PDF legal.

- Brand công khai: `PTTCRM`. CI fail nếu `RNOSAI` trong `apps/web` hoặc CMS publish body/alt.
- CTA chính vẫn `Request demo` / `Đăng ký Demo`. Stripe W2 = **test mode** + secondary CTA «Pay setup (test)» — **không** thay demo làm CTA chính.
- **Không** trial 30 ngày. **Không** giá/user < `200000` VND hoặc < `15` USD/user/tháng (Master §6.3).
- USD list **chỉ** khi `NEXT_PUBLIC_USD_PRICE=1`. Flag `0` → EN pricing giữ copy W0/W1 (`showAmounts: false`).
- List price USD cố định repo (BR-GTM-025): `mkt` 199/400 · `ind` 399/600 · `agy` 799/1200 USD.
- Stripe secrets chỉ env RNOSAI: `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `STRIPE_PRICE_*` (test). **Không** commit keys.
- Sandbox EN (FR-SAN-008): whitelist `/login`, `/sandbox/leads`, `/sandbox/board/{industry}` — **không** lộ nav 129 route.
- Commit site trong PTTCRM; Stripe/webhook/sandbox auth trong `../RNOSAI`. Không trộn hai repo một commit.
- `/vi/bang-gia` **không** đổi — VND only.

Work in `/Users/quoctuan/Documents/CursorAI/RNOSAI`.

- Create: `scripts/apply_pg_ddl_gtm_w2_payment.sh`

```sql
CREATE TABLE IF NOT EXISTS gtm_payment (
  id                   uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  created_at           timestamptz NOT NULL DEFAULT now(),
  updated_at           timestamptz NOT NULL DEFAULT now(),
  stripe_session_id    text NOT NULL UNIQUE,
  stripe_payment_intent text,
  sku                  text NOT NULL CHECK (sku IN ('mkt', 'ind', 'agy')),
  amount_cents         integer NOT NULL CHECK (amount_cents > 0),
  currency             text NOT NULL DEFAULT 'usd',
  status               text NOT NULL DEFAULT 'pending'
                         CHECK (status IN ('pending', 'paid', 'failed', 'expired')),
  payer_email          text NOT NULL,
  demo_request_id      uuid REFERENCES gtm_demo_request(id),
  metadata             jsonb NOT NULL DEFAULT '{}'::jsonb
);
CREATE INDEX IF NOT EXISTS idx_gtm_payment_status ON gtm_payment(status, created_at DESC);
```
