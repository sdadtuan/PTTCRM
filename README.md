# PTTCRM

**Một nền tảng, chuyên biệt từng ngành.**  
Marketing CRM — brand công khai. Engine vận hành: RNOSAI (`../RNOSAI`).

| Wave | Hướng | Mục tiêu |
|------|--------|----------|
| **W0** | A+ + D0 | Site bán VI/EN, demo → CRM, 3 SKU, 3 ngành |
| **W1** | A+ chốt | Case số thật, sandbox 14 ngày, Excel/PDF table stakes |
| **W2** | D0 sâu | USD/Stripe, GDPR, i18n app |
| **W3** | D1 ASEAN | Playbook TH/ID/PH/SG |
| **W4** | US/EU | SOC2, region Singapore — không bắt đầu trước D1 |
